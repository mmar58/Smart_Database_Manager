      Search Tips

      • Single filter: Select a column, type a value, and click Search.
      • Multi filter: Click "+ Add Filter" to add more filter rows.
      • AND logic: All filters must match (narrows results).
      • OR logic: Any filter can match (broadens results).
      • LIKE matching: Searches for partial matches (e.g. "john" matches "Johnson").
      • Not Contains: Use the operator dropdown to exclude rows matching the value.
      • Clear: Resets all filters and shows all data.
      • Page Jump: Type a page number and click Go to jump directly.
